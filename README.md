# TRIZ 创新方法速查工具
简洁易用的 TRIZ 矛盾矩阵查询工具，专为工程创新与问题解决设计。

## 功能简介
- 完整 39×39 矛盾矩阵，支持横向滚动，**第一列固定不动**
- 单元格完全不透明，滚动无重叠、不遮挡
- 支持快捷查询、随机示例、点击查看原理详情
- 内置 39 个工程参数 + 40 个发明原理速查
- 左对齐排版，界面清爽、操作直观

## 使用说明
1. 选择「欲改善的参数」与「被恶化的参数」
2. 点击查询或直接在矩阵中点击单元格
3. 查看推荐发明原理及说明
